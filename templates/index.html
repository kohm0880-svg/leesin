분석 리포트

특이도 점수는 target rows가 들어간 bin의 peer count를 occupied peer bin count 분포와 비교한 eCDF 기반 점수입니다. 1에 가까울수록 기존 peer density map에서 낮은 밀도 또는 미관측 bin에 위치한다는 뜻이며, p-value나 사후확률은 아닙니다. Confidence는 Observation Support, Coverage, Equitability를 종합한 engineering confidence입니다.

분석을 실행하면 리포트가 여기에 표시됩니다.

실험 목적 / 관리

Goal, Axis, Bin Preview, 저장된 record Audit을 한 곳에서 관리합니다. 원본 CSV, 파일명, unmapped column, 개인정보 column은 저장하지 않습니다.

계산 기준
External uses saved peers only, Pooled uses saved peers plus the target, and Internal uses the target only. Each mode calculates its own Specificity and Confidence; the three results are not combined.
